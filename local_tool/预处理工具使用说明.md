# 短视频批改 · 本地预处理工具使用说明（Windows）

> 作用：把全班视频（可能 5–10 GB）在你的电脑上压成一个约 100–200 MB 的
> "批改包"，只有音频、转写稿、口语指标、关键帧进包——**视频原片不上传、不出电脑**。

## 一、一次性安装（只做一次，约 15 分钟）

1. **装 Python**：到 https://www.python.org/downloads/ 下载 Python 3.11+，
   安装时务必勾选 **"Add Python to PATH"**。
2. **装依赖库**：按 `Win + R` 输入 `cmd` 回车，在黑窗口里粘贴运行：
   ```
   pip install faster-whisper imageio-ffmpeg
   ```
   等它跑完（几分钟）。ffmpeg 会随 imageio-ffmpeg 自动带上，不用单独装。
3. 把 `yuchuli.py` 存到一个固定位置，比如 `D:\短视频批改\yuchuli.py`。

## 二、每次批改的操作（每学期重复这一段）

1. 从谷歌课室**批量下载**全班视频，放进一个文件夹，例如
   `D:\短视频批改\3A班_短视频`。
   - 命名规则：个人 `05.mp4`；两人组 `05_12.mp4`（两个学号下划线相连）。
   - Windows 重复下载产生的 `05 (1).mp4` 括号编号会被自动忽略，不用改名。
2. 打开 cmd，运行：
   ```
   python D:\短视频批改\yuchuli.py D:\短视频批改\3A班_短视频
   ```
3. **第一次运行**会先下载转写模型（约 500 MB，只下载一次），之后开始逐个
   处理。屏幕上能看到进度：`[3/35] 07.mp4 … 完成 ✓`。
   - 35 个 4 分钟视频，普通笔记本预计 **40–90 分钟**，可以放着去喝茶。
   - 中途断了？直接重跑同一条命令，已完成的自动跳过。
   - 某个视频失败会列在结尾清单里，其余不受影响。
4. 跑完后，视频文件夹旁边会出现 `批改包_日期_时间.zip`。
5. 打开批改平台网页，上传这个 zip → 之后就是熟悉的流程：
   队列批改 → 复核表 → 下载报告 ZIP → 谷歌课室退还。

## 三、批改包里有什么（每个学生/组一个文件夹）

| 文件 | 用途 |
|---|---|
| transcript.json | 带时间戳的转写稿 + 口语指标 + 准入检查预判（AI 批改主依据） |
| audio.mp3 | 32kbps 音频（约 1MB），复核时点开抽听，不用翻原视频 |
| frame_01~08.jpg | 8 张关键帧，GLM-4V 判"拍摄与呈现"和面容出镜 |

口语指标包括：语速（字/分钟）、明显停顿（≥1.5秒）的次数和位置、
嗯呃填充词次数、"然后"口头禅次数、英文夹杂比例。这些是**复核参考**，
不直接决定分数。

## 四、常见问题

- **转写不准怎么办？** 默认用 small 模型（快）。如果试批后发现转写错字
  影响判断，改用 `python yuchuli.py 文件夹 --model medium`（更准，速度
  约慢一半，首次需再下载约 1.5 GB 模型）。
- **学生用 iPhone 拍的 .mov 可以吗？** 可以，mp4/mov/m4v/avi/mkv/webm 都支持。
- **"python 不是内部或外部命令"**：安装 Python 时没勾 Add to PATH，
  重装一次并勾选即可。
